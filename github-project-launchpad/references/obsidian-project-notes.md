# Obsidian Project Notes

Store project-introduction notes under one shared root inside the main vault.

## Default Location

- Vault root: `D:\Documents\笔记`
- Project notes root: `D:\Documents\笔记\项目介绍`
- Per-project folder: `D:\Documents\笔记\项目介绍\<project-name>`
- Main note filename: `项目介绍.md`

## Chinese Properties

Use these properties by default in YAML frontmatter:

- `标题`
- `项目名`
- `项目代号`
- `项目类型`
- `项目状态`
- `项目分区`
- `架构类型`
- `本地路径`
- `GitHub仓库`
- `技术栈`
- `标签`
- `创建日期`
- `更新时间`

## Default Chinese Tags

- `项目`
- `开发`
- `网站项目`
- `全栈项目`
- `接口项目`
- `自动化项目`
- `内部工具`
- `组件库`

Pick the archetype-specific tag in addition to `项目` and `开发`.

## Note Structure

1. One-line summary
2. Problem and goal
3. Recommended architecture
4. Local path and GitHub repo
5. Milestones
6. Key decisions
7. Open questions

## Rules

- Keep the project note concise and navigable.
- Use Chinese properties by default because the user's working language is Chinese-first.
- Do not treat the Obsidian note as the only source of truth; it is a project-facing mirror and control panel.
